# Custom Project Rules for Scrapper_fasih

- **Git Auto-Commit & Auto-Push Control**:
  Jangan pernah melakukan `git commit` atau `git push` secara otomatis setiap kali melakukan perbaikan/edit kode. Biarkan user melakukan commit & push secara manual, atau HANYA lakukan `git commit`/`git push` jika user secara eksplisit memintanya di chat.
